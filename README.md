# Les couleurs de la famille

Application web pour aider les parents à découvrir le profil de comportement de leur enfant, à mieux lui parler, et à mieux se comprendre en couple.

Elle s'appuie sur le modèle des 4 couleurs (inspiré du DISC) :

| Couleur | Symbole | Style |
|---|---|---|
| Jaune | Soleil | Inspiration |
| Vert | Feuille | Cohésion |
| Rouge | Flamme | Action |
| Bleu | Goutte | Précision |

## Fonctionnalités
- Questionnaire enfant de 24 questions (8 sur le tempérament, 16 situations du quotidien)
- Questionnaire pour la maman et le papa
- Analyse croisée du couple : papa lit maman, maman lit papa
- Conseils pour parler à l'enfant, gérer son stress et l'accompagner dans les moments difficiles
- Trois langues : français, arabe et anglais
- Les profils restent sur l'appareil du parent (stockage local du navigateur), rien n'est envoyé en ligne

## Utilisation
Ouvrir `index.html` dans un navigateur, ou via GitHub Pages.

Le dossier `reels/` contient les vidéos de présentation pour Instagram.

Ce questionnaire est un outil de communication, pas un diagnostic.
